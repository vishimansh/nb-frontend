Architecture Overview
Context · Guard · Storage · Route Map · Campaign Lifecycle

Context Provider

AdvertiserContext.jsx wraps the entire app inside AdvertiserProvider. Exposes all advertiser state + actions via useAdvertiser() hook to every screen.

Route Guard

AdvertiserGuard.jsx protects all 8 campaign-creation routes (Goal→Payment). Redirects unauthenticated users to /advertise/intro and incomplete-profile users to /advertise/business-profile.

Persistent Storage (localStorage)

nb_advertiser_auth · nb_business_profile · nb_business_profile_saved · nb_campaigns. Draft wizard state uses sessionStorage: nb_draft_campaign.

Auth Model

Separate from the reader app session. Uses advertiserAuth object: { isAuthenticated, phone, otpVerified }. Guard enforces both isAuthenticated AND otpVerified must be true.

Global State (AdvertiserContext)

VariableTypeStorageDescription
advertiserAuthObjectlocalStorage{ isAuthenticated, phone, otpVerified } — independent login session
businessProfileObjectlocalStoragePersistent across campaigns: name, category, address, Aadhaar, GSTIN, logo
isBusinessProfileSavedBooleanlocalStoragetrue only after Aadhaar (12-digit raw) verified in Location-Tax screen
draftCampaignObjectsessionStorageAccumulates all 7 wizard steps; reset after payment via commitCampaign()
campaignsArraylocalStorageAll committed campaigns with status: pending_review / live / paused
🔐
Guard checks: (1) isAuthenticated && otpVerified, (2) isBusinessProfileSaved && businessName.trim().length > 0 && idNumberRaw.length === 12. The 12-digit raw Aadhaar check prevents a 4-digit profile OTP from bypassing KYC.

Campaign Lifecycle & CTR by Goal

🟡 pending_review

Created after payment. Auto-transitions to live after 5 seconds via 250ms polling interval. User can also approve instantly via "तुरंत लाइव करें" button.

🟢 live / ⚪ paused

User toggles between live and paused via status button. Metrics shown at full/70% opacity. Budget can be edited from both states via BudgetEditSheet.

CTR Model

reach: 0.94% CTR  |  engagement: 1.25% CTR  |  ctrs: 1.60% CTR — used in commitCampaign() to compute realistic click counts from impressions.

commitCampaign() Security

On commit: idNumberRaw is explicitly set to undefined in the stored campaign object — raw Aadhaar never stored in the campaigns array.

2
Phone Number Screen
/advertise/phone
Collects the advertiser's Indian mobile number. Validates for exactly 10 digits starting with 6–9. Stores phone in advertiserAuth context.

Input Field

Composite input: +91 prefix (non-editable) + vertical divider + numeric text field. inputMode="numeric", maxLength=10, auto-focused on mount.

CTA Button

Enabled only when phone.length === 10. Label: "आगे बढ़ें" + ArrowRight icon. Disabled state: 40% opacity, cursor-not-allowed.

Validation Rules

  • Empty → "कृपया अपना 10 अंकों का मोबाइल नंबर दर्ज करें।"
  • Fails /^[6-9]\d{9}$/ → "कृपया मान्य भारतीय मोबाइल नंबर दर्ज करें (6-9 से शुरू)।"
  • Non-digits stripped in real-time via replace(/\D/g,'')
  • Error clears when length becomes 0 or 10
  • On submit: Sets advertiserAuth.phone → navigates to /advertise/otp
  • Back: Returns to /advertise/intro
3
OTP Verification Screen
/advertise/otp
6-digit OTP entry with individual cell boxes, 30-second resend timer, and auto-advance focus. On success, marks session as fully authenticated.

OTP Input UI

6 cells, each 45×58px. Auto-advances on digit entry. Backspace moves focus back. Full OTP paste supported via onPaste handler. Unfilled cells show a bottom underline indicator.

Resend Timer

Starts at 30 seconds, counts down every second. Timer > 0: shows "दोबारा भेजें 00:XX". Timer = 0: shows "OTP दोबारा भेजें" button → resets timer + clears all cells.

Phone Display

Shows "+91 XXXXXXXXXX" read from advertiserAuth.phone (set by PhoneScreen or IntroScreen pre-fill). Falls back to businessProfile.phone for returning users. "नंबर बदलें" link → /advertise/phone.

On Verify

Sets: isAuthenticated=true, otpVerified=true, phone. Calls updateDraftCampaign({phone}). If !isBusinessProfileSaved → /business-profile, else → /dashboard.

Validation

  • Fewer than 6 digits → "कृपया सभी 6 अंकों का ओटीपी कोड दर्ज करें।"
  • Non-digits stripped via replace(/\D/g,'')

Business Profile Screen
/advertise/business-profile
Two-card form collecting all business identity: logo upload, name, category, contact info, and store address. Pre-populates from existing businessProfile for returning users.

Logo Upload

Circular 96×96px avatar with camera badge. Shows first letter of businessName as fallback. Accepts image/* files, converts to base64 via FileReader, stored as businessLogoUrl.

Phone Field

Read-only pre-fill from OTP session. Shows "+91 XXXXXXXXXX" with gold Verified badge (TickCircle icon). Cannot be edited on this screen.

Card 1: Business Information

  • बिज़नेस का नाम * Required. Shop icon. Triggers error if empty.
  • मालिक का नाम Optional. Placeholder: "जैसे: राजेश शर्मा".
  • बिज़नेस श्रेणी * Required dropdown. 13 options: किराना, कपड़े, इलेक्ट्रॉनिक्स, रेस्टोरंट, मेडिकल, शिक्षा, हार्डवेयर, ज्वेलरी, मोबाइल, ब्यूटी, ऑटो, कृषि, अन्य.
  • ईमेल (ऑप्शनल) Regex validated if provided: /^[^\s@]+@[^\s@]+\.[^\s@]+$/

Card 2: Store Address

  • पता या इलाका Optional. Placeholder: "दुकान / ऑफ़िस का पता या इलाका डालें".
  • पिन कोड Optional. Numeric only, max 6 digits. Validated as exactly 6 if provided.

Validation

  • businessName empty → "कृपया अपने बिज़नेस का नाम दर्ज करें।"
  • businessCategory not selected → "कृपया अपने बिज़नेस की श्रेणी चुनें।"
  • Invalid email → "कृपया एक मान्य ईमेल पता दर्ज करें (उदा. info@business.com)।"
  • Pincode provided but not 6 digits → "कृपया 6 अंकों का मान्य पिन कोड दर्ज करें।"
  • On submit: updateBusinessProfile(data) + updateDraftCampaign(data). fromReview → /review | fromDashboard → /location-tax?fromDashboard | Default → /location-tax
5
Location & Tax Screen — KYC Gate
/advertise/location-tax
Aadhaar (12-digit) identity verification and optional GSTIN collection. Completing this screen sets isBusinessProfileSaved=true, which unlocks AdvertiserGuard and the full campaign wizard.

Aadhaar Input

Formatted as "XXXX XXXX XXXX" (groups of 4). Numeric only. Toggle show/hide (Eye/EyeSlash icon). Raw 12 digits stored as idNumberRaw; masked last-4 as idNumberMasked (e.g. •••• •••• 3456).

GSTIN Section

Checkbox "मेरे पास GST नंबर नहीं है" (default checked = hasGstin:false). If unchecked, 15-char GSTIN input appears. Validated against standard GSTIN regex + state code 01–37.

Validation Rules

  • Aadhaar < 12 digits → "कृपया आधार कार्ड के पूरे 12 अंक दर्ज करें।"
  • Progress hint while typing 1-11 digits: "कृपया X अंक और दर्ज करें"
  • Success at 12 digits: "✓ आधार के पूरे 12 अंक दर्ज हैं" (green indicator)
  • Invalid GSTIN on blur → "अमान्य जीएसटी नंबर: कृपया 15 अक्षरों का सही प्रारूप दर्ज करें (उदा. 23AAAAA0000A1Z5)।"
  • CTA disabled unless: isIdValid && (!hasGstin || isGstinValid)
  • On submit: updateBusinessProfile(taxData) + updateDraftCampaign(taxData) + setIsBusinessProfileSaved(true) — UNLOCKS AdvertiserGuard
  • Navigation: fromReview → /review | fromDashboard → /dashboard | Default → /advertise/goal

Audience Screen — Wizard Step 4 of 7
/advertise/audience
Step 4 / 7 · Protected by AdvertiserGuard
Four collapsible accordion sections for fine-grained audience targeting. All optional — user can skip. Each selection refines real-time reach estimation using a formula.

Reach Formula

baseReach × genderMul × ageMul × catBonus. Min: 1,200. genderMul: Male=0.52, Female=0.48, All=1.0. ageMul: selectedAges.length/4 (min 0.25). catBonus: 0.72 + (selectedCats × 0.05), max 1.0.

Skip Option

Budget Screen — Wizard Step 6 of 7
/advertise/budget
Step 6 / 7 · Protected by AdvertiserGuard
Financial configuration step. Custom slider for daily budget, duration stepper (1-90 days), start date input, and a live billing card showing subtotal + 18% GST + grand total in real-time.

Daily Budget Slider

Range: ₹100 (min) to ₹2,500 (max), step=25. Floating tooltip above drag point. Landmark dots at ₹500, ₹1,000, ₹1,500, ₹2,000. Quick presets: ₹250, ₹500, ₹1,000, ₹1,500. Default: ₹300/day.

Duration Stepper

− and + buttons. Range: 1 to 90 days. Default: 7 days. Start date field in DD-MM-YYYY format, defaults to today. getTodayFormatted() helper used.

Billing Card (Dark)

Dark #2B2437 card: Subtotal = dailyBudget × durationDays · +18% GST = subtotal × 0.18 · Grand Total displayed in amber/gold. GST invoice promised after payment.

Reach Estimate

Formula: min(baseReach × 3.5, max(1200, dailyBudget × 28.5 × (durationDays/7))). Shown in warm amber card with estimated local readers count.

State Saved on Proceed

  • dailyBudget — ₹100–₹2,500 (number)
  • durationDays — 1–90 (number)
  • startDate — DD-MM-YYYY string
  • estimatedReach — computed reach number
  • subtotal, grandTotal — billing amounts including 18% GST
📌
Budget screen always navigates to /advertise/review regardless of fromReview flag — it IS the final step before review.
